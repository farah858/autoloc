# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

## Objectifs du projet
Développer une application Spring Boot permettant la gestion des locations de véhicules à travers plusieurs agences.

## Acteurs identifiés
- **Client** : réserve et loue des véhicules
- **Agent d'agence** : gère les réservations et les véhicules au quotidien
- **Responsable d'agence** : supervise l'activité de son agence
- **Administrateur** : gère l'ensemble du système et des agences
